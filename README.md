# 🌦️ Weather App - Android (Kotlin + MVVM)

This is a simple yet functional Weather App built using Kotlin and the MVVM architecture. The app allows users to search for weather information by city name or use their current location to get live weather data including temperature, description, humidity, wind speed, and precipitation.

---

## ✨ Features

- 🔍 Search weather by city name
- 📍 Auto-fetch weather using current location
- 🌡️ Temperature display in Celsius
- 🌬️ Wind speed, 💧 humidity, and ☔ precipitation data
- 📶 Real-time data from a weather API
- 🧠 Clean architecture using MVVM
- 💙 Modern and responsive UI with ConstraintLayout
- 📦 Room for future expansion (e.g., forecast, favorites, themes)

## 🛠️ Tech Stack

- **Language:** Kotlin
- **Architecture:** MVVM (Model-View-ViewModel)
- **UI:** XML, ConstraintLayout
- **API:** Weather API (e.g., OpenWeatherMap)
- **Location Services:** FusedLocationProviderClient
- **Permissions:** Runtime permission handling for location
- **Data Binding:** ViewModel LiveData updates UI reactively
